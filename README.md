# Healthcare Data Analysis – Radiology Workflow

## 📌 Project Overview

This project analyzes a simulated radiology workflow to understand case volumes, VRA assistance, radiologist productivity, and staffing patterns.

The data is simulated for portfolio purposes and contains no real patient information.

## 🛠️ Tools Used

* Microsoft Excel
* MySQL
* Power BI
* GitHub

## 🎯 Analysis Questions

### 1. VRA Attendance vs Radiologist Productivity

Analyzed whether higher VRA attendance was associated with higher radiologist case finalization.

### 2. Queue Movement

Compared Start-of-Day (SOD) and End-of-Day (EOD) case counts to identify days when the pending case volume increased or decreased.

### 3. Ideal Team Composition

Analyzed VRA and radiologist staffing levels against case output to identify a suitable team composition for efficient workflow.

## 📊 Project Workflow

**Excel → MySQL → Power BI**

Data was prepared and analyzed using Excel and MySQL, followed by the development of an interactive Power BI dashboard.
